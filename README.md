# מערכת לניהול, עריכה והתאמת קורות חיים מבוססת AI

מערכת אוטומציה מבוססת Python המשלבת ממשק Web מקומי (Flask), ארכיטקטורת AI היברידית (Google Gemini API לצד מודל מקומי חינמי ב-Ollama), ומנוע הפקת מסמכים (Word ו-PDF)[cite: 8].
המערכת מנהלת קורות חיים במבנה נתונים מובנה (JSON), מאפשרת עריכה והוספה חיה של פריטים לצמיתות, ומבצעת התאמה דינמית של תמצית קורות החיים לדרישות משרה ספציפית תוך שמירה על עיצוב אחיד ותמיכה דו-לשונית מלאה (עברית ואנגלית)[cite: 8].

---

## תכונות מרכזיות

- **ארכיטקטורת AI היברידית (Cloud & Local):** תמיכה כפולה במודל ענן חכם ומתקדם (Google Gemini API) עבור תוצרים סופיים מלוטשים, לצד תמיכה במודל מקומי (Ollama - Llama 3.2) לבדיקות ופיתוח ללא עלות וללא צריכת טוקנים, כולל מנגנון Fallback אוטומטי במקרה של תקלת רשת.
- **התאמה למשרה ודיוק אינטראקטיבי מול הסוכן:** שכתוב מקצועי של תקציר קורות החיים בהתאם לדרישות המשרה וכישורי המועמדת[cite: 8], לצד תיבת שיחה והכוונה המאפשרת לבקש מהסוכן לדייק, לקצר או לשנות סגנון בשפה חופשית.
- **עריכה חופשית בלייב של התוצר:** תיבת עריכה מקדימה המאפשרת למשתמשת לבצע שינויים ידניים עדינים בתקציר שנוצר לפני הפקת הקבצים הרשמיים.
- **ממשק משתמש אינטראקטיבי עם חיווי טעינה:** מסך טעינה חכם (Loading Overlay & Spinner) המספק משוב ויזואלי בזמן אמת על פעולות הסוכן והמרות הקבצים ומונע לחיצות כפולות.
- **ניהול ועריכה של מסד הנתונים בלייב:** ממשק Web המאפשר הוספה, החלפה ומחיקה של פרויקטים, מיומנויות, קורסים ותקצירים ישירות בקובצי ה-JSON המקוריים לצמיתות[cite: 8].
- **הפקה כפולה ואריזה:** יצירת מסמכי Word מעוצבים והמרתם ל-PDF, ואריזת התוצרים בקובץ ZIP מותאם להורדה ישירה[cite: 8].
- **תמיכה מלאה ב-RTL:** הגדרות כיווניות מימין לשמאל ברמת ה-XML עבור תבליטים, סוגריים ופרטי התקשרות[cite: 8].

## מבנה התיקיות והפרויקט

יש לוודא שהתיקיות והקבצים מאורגנים במבנה הבא כדי שהקוד ירוץ בצורה תקינה[cite: 8]:

```text
resume-automation/
│
├── Resume/                          # תיקיית קובצי המקור של הנתונים (חובה)
│   ├── Hebrew_Resume.json           # נתוני קורות החיים בעברית
│   └── English_Resume.json          # נתוני קורות החיים באנגלית
│
├── generated_resumes/               # תיקיית פלט לתוצרים (נוצרת אוטומטית בעת ריצה)
│
├── app.py                           # שרת ה-Flask, ניהול הניתובים, הלוגיקה וממשק המשתמש
├── ai_agent.py                      # לוגיקת סוכן ה-AI (ניהול Gemini ו-Ollama, התאמה ודיוק)
├── generate_word.py                 # מנוע יצירת מסמך ה-Word וטיפול בעיצוב
│
├── .env                             # קובץ משתני סביבה (מפתח API ובחירת ספק AI)
├── .gitignore                       # קובץ התעלמות עבור Git
└── requirements.txt                 # רשימת החבילות הנדרשות להתקנה
```[cite: 8]

## הגדרת משתני סביבה (`.env`)[cite: 8]

יש ליצור קובץ בשם `.env` בתיקיית השורש של הפרויקט ולהגדיר את הפרטים הבאים[cite: 8]:

```env
# מפתח ה-API של גוגל (עבור מודל Gemini)
GEMINI_API_KEY=your_api_key_here

# בחירת ספק ה-AI: 'gemini' לעבודה שוטפת ומדויקת, או 'ollama' לבדיקות חינמיות
AI_PROVIDER=gemini

# שם המודל המקומי ב-Ollama (במידה ומשתמשים ב-ollama)
OLLAMA_MODEL=llama3.2
